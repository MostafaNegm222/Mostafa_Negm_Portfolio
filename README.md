# Mostafa Negm - Portfolio

## 1. Description

Mostafa Negm's personal portfolio website (latest version): a single-page site presenting his work, with his resume available as a PDF.

## 2. Technologies and Versions

- HTML5, CSS3, vanilla JavaScript (no build step)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/Mostafa_Negm_Portfolio.git
cd Mostafa_Negm_Portfolio
```

Open `index.html` in a browser, or serve the folder with any static server.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- Single-page portfolio (`index.html`, `style.css`, `script.js`, `images/`).
- Resume and documents under `PDF/`.

## 7. Screenshots / Demo

The site is published with GitHub Pages from this repository.

## 8. Running Tests

No automated tests in this repo.
